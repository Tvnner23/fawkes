deferred. Only demonstrated release, source-dependency and verification blockers
are brought forward. This page is navigation, not a grant or acceptance ledger.

with the current interpreter and repository working directory. Existing
prospective recording controls remain authoritative; launching Chat does not
authorize an import, Memory repair or another Phoenix identity.

and its fallback renderer is not proof of live 3D embodiment.

source companions referenced by the canonical roadmap and historical capture.
Their dated phase-status prose preserves the original evidence slice. Adopting
these files does not recertify historical phase completion, activate an import,
implement future personality mechanisms or supersede later accepted amendments.

## Historical inventory versus accepted current source

`repository-work-inventory.json`, its source-bindings fixture and the September
8 implementation capture remain byte-for-byte historical records. A clean
accepted successor must not be required to match the original 126 unfinished
files: accepted corrections deliberately changed those bytes. The portable
regression checks validate all historical bindings, classifications and digests.
The optional material-root check separately detects changed bytes, modes and
missing files against an explicitly selected original capture. It does not
silently treat the current checkout as that original capture. External original
preservation evidence remains separate from current-source Git/review evidence.

## Gates

Run affected launcher, approval-identity, authenticated HTTP/DOM and document
checks, the full regression suite in a clean disposable source checkout, static
and diff checks, and the actual guarded delivery/recovery rehearsal. Preserve
failed runs and their exact subjects. Conditional paid-provider/Windows trial
tests require their own existing route evidence or explicit authorized run;
skipped tests must remain reported, not counted as passing.

Independent review and exact acceptance precede integration. Private GitHub
backup requires outgoing privacy screening, non-force push and remote readback.
Source acceptance is not deployment. Native credentials, a coherent private
backup/isolated restore, installed served-build checks, real desktop/iPhone use
and the seven-day trial remain distinct evidence gates in
[the startup checklist](ALPHA_STARTUP_TRIAL.md).
